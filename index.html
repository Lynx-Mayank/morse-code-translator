The History of Morse Code

Morse code is a method used in telecommunication to encode text characters as standardized sequences of two different signal durations, called dots and dashes, or dits and dahs.

1830s

Samuel Morse and Alfred Vail developed the electric telegraph system.

1844

First message sent: "What hath God wrought" from Washington D.C. to Baltimore.

1900s

Became the standard for maritime and aviation communication for over a century.

Why is it still relevant?

Despite the digital revolution, Morse code remains popular among amateur radio enthusiasts. It is also a vital backup communication method in emergency situations where voice transmission is impossible or signals are weak. Because it requires very little bandwidth, Morse code can be heard through static that would make voice communication unintelligible.

How to Learn Morse Code

The 5 Rules of Timing

  • The length of a dot is 1 unit.
  • The length of a dash is 3 units.
  • The space between parts of the same letter is 1 unit.
  • The space between letters is 3 units.
  • The space between words is 7 units.

Memorization Tips

Don't try to count dots and dashes visually. Morse code is an auditory language. Try to learn the rhythm of the letter.

A .- (di-dah)
B -... (dah-di-di-dit)
O --- (dah-dah-dah)
S ... (di-di-dit)
